# Templates de sites

Cinco modelos responsivos em HTML, CSS e JavaScript puros, sem dependências. Cada pasta é um site independente.

| Pasta | Tipo | Indicado para |
|---|---|---|
| `01-institucional` | Site institucional | Empresas de serviços, indústrias, escritórios e prestadores B2B. |
| `02-landing-page` | Landing page de conversão | Campanhas de tráfego pago, lançamento de serviço ou produto, captação de leads. |
| `03-portfolio` | Portfólio | Designers, fotógrafos, arquitetos, ilustradores e freelancers. |
| `04-restaurante` | Restaurante / delivery | Restaurantes, pizzarias, hamburguerias, cafés e confeitarias. |
| `05-profissional-servicos` | Profissional liberal / consultório | Médicos, dentistas, psicólogos, advogados, contadores, nutricionistas, esteticistas. |

Cada pasta tem o próprio README com a lista de marcadores `{{...}}` a substituir e as configurações do `script.js`.

## Dica

Transforme cada pasta em um repositório no GitHub e marque **Settings > Template repository**. Para um cliente novo, use **Use this template** e gere uma cópia limpa.
